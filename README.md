# 职伴 AI（JobMate-AI）· 隐私优先的全行业开源求职助手

> 🌐 **手机 / 微信在线即用版（免安装、无需电脑、零隐私上云）**：
> **https://eason-chen2026.github.io/JobMate-AI/**

一款**零第三方 npm 依赖、隐私优先、电脑 + 手机全端可用**的开源求职全流程助手，覆盖 **应届大学生、AI 转型、软件研发、数据分析、产品设计、内容运营、B2B 销售、电商直播、带货主播、HR/行政、财务法务及全行业通用岗位**。

## 核心亮点

1. **隐私隔离与强制脱敏**
   - 电脑版程序源码与个人数据目录物理隔离，姓名、手机号、邮箱、微信与自定义敏感词在任何 AI 外发前自动打码并留存审计日志；
   - 手机在线静态版（GitHub Pages）所有个人记录仅保存在自己手机浏览器本地（`localStorage`），**不经过、不存储于任何后端服务器**。
2. **13 大全行业普适模板库 + 3 类人群阶段**
   - 覆盖应届生 / 社招 1-5 年 / 资深管理者，内置 13 大行业深度面试题（答题框架 + 长示范答案 + 面试官连环追问 + 踩坑预警）、行业典型薪资结构防坑百科与 **6 维度面试者反向考察清单**。
3. **双模式 AI 引擎（零 API 费也能玩转）**
   - **模式 B（零 API 协作模式）**：本地自动脱敏导出任务包，交由你常用的 AI 助手处理后一键回填还原；
   - **模式 A（官方 API 直连）**：直连 DeepSeek / Google Gemini / OpenAI 兼容官方接口，本地脱敏后一键打分、定制简历、生成 PDF、模拟面试与聊天回复。
4. **全流程求职闭环**
   - **搜岗与适配简历**：一键直达 Boss直聘 / 猎聘 / 智联 / 实习僧搜岗；可视化主简历底稿（支持 `.docx` 离线导入与公司下挂多段子项目）；按选中岗位一键生成适配简历与高清 A4 PDF；
   - **面试模拟与谈薪博弈**：多轮 AI 模拟面试逐轮打分点评、6 大场景 HR 聊天神回复、谈薪锚点计算器与 6 大压薪反制剧本；
   - **职业规划与技能提升**：未知方向多路线定位、已有目标岗位技能缺口诊断与可打卡练习清单；
   - **投递复盘看板**：追踪已读率、回复率、约面率、话术风格对比与高频技能缺口。

## 快速开始

### 方式一：手机 / 浏览器直接在线使用（免安装、无需电脑）
部署 GitHub Pages 后直接打开仓库对应的 `https://<你的用户名>.github.io/<仓库名>/` 网址即可在微信或手机浏览器直接使用，支持「添加到主屏幕」像 App 一样全屏运行。

### 方式二：电脑本地运行完整版（含 SQLite 台账、Chrome 离线高清 PDF 与隔离求职浏览器）
需安装 Node.js >= 24（零 `npm install` 第三方依赖）：

```bash
node src/server.mjs
```

Windows 用户也可直接双击 `启动求职助手.bat`，然后浏览器打开 `http://127.0.0.1:3456`。

- 支持在「隐私与 AI 设置」中开启 **同 Wi-Fi 手机安全访问（强制 6 位 PIN 口令）**；
- 运行自动化自测：`npm test`
- 重新构建 GitHub Pages 纯净通用静态站：`npm run build:pages`
